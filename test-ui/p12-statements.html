P12a · statement upload → scan → ai-parser → review → confirm

POST /api/v1/statements/uploads (Idempotency-Key) returns a presigned PUT into a quarantine key; the browser PUTs the PDF straight to the object store (S3 identities: unsigned requests are refused); …/{id}:submit (Idempotency-Key, Mode B) scans it (PDF magic, size cap, SHA-256), keeps a clean copy and emits portfolio.statement.submitted; the Python ai-parser redacts card numbers, reads one of three MOCK_ layouts and answers ai-parser.statement.parsed; review the lines, untick any, then :confirm turns them into card transactions (each line once, ever) or :discard.
