P18 · audit, notifications, privacy

Every audited action is one link of a hash chain: each row carries the previous row's hash and its own, so editing a row - or rewriting every row after it - is caught by verify-chain (and by the anchors exported along the way). Events from identity, planning, billing and commerce become notifications: in-app always, email and push by preference, security never muted, a failed delivery retried with exponential backoff. A privacy request is a saga across seven services: an export zips every service's part; a deletion freezes the account, erases it everywhere, shreds its data key and leaves a pseudonym. Mock does all of it in this browser; Live drives the real stack. Testing aid only - deleted in P19.
