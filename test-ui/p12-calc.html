P12b · the ported calc engines behind /v1/calc/*

Every engine from the old repo's portfolio/calc package, ported to libs/portfolio-calc with its tests as golden fixtures (ADR-0018): paise and basis points in and out, BigDecimal rupees and the original's rounding inside. The endpoints are POST only, hold no state and touch no database, so there is no Idempotency-Key, no ETag and no paging — the rate-limit class is calc (60 a minute per account). Every form below is pre-filled with a ported fixture's own inputs. Mock mode replays that fixture's recorded answer; Live mode runs the real engines through the gateway. The numbers must be identical — that is the point of the page. Change an input and Mock mode says so rather than inventing an answer: there is one implementation of this arithmetic and it is not in the browser. Testing aid only - deleted in P19.

₹6,000 at 36 %: the smallest flat payment that clears it in 3 cycles is found by binary search over the same ledger math, not a closed-form shortcut.

6 · Limits

The engines loop over days, cycles and lots, so the service bounds every list and count and caps a body at 64 KB (inside the gateway's 256 KB). These must be refused, not computed. With no persona selected every endpoint answers 401 — the route is token-only. In Mock mode these three come back MOCK_FIXTURE_ONLY (the mock replays fixtures and nothing else); switch to Live to see the service's own 400 with the field that was out of range.
