P10 · catalog ingestion: collector → review → promoter

Admin endpoints: /api/v1/admin/ingestion/sources (CRUD, If-Match), …/sources/{id}/runs and …/runs (202, the worker crawls), /api/v1/admin/review (keyset, oldest first) and /api/v1/admin/review/{id}:approve|:reject. Approve runs the promoter - the only writer of published data - which creates the card's next version; a second approve answers the same promotion. Mock mode serves a mock issuer page from fixtures/p10-source.json: change the fee on the page, run, approve, watch the version. Live mode needs an admin token (sign in on p05-mfa-admin.html) and a source on an allowlisted host. Testing aid only - deleted in P19.
