P15 · the wallet, the card for this purchase, and the push

P14 answered which card should I get. P15 answers three harder ones. The wallet: a rupee is spent once, so two cards are only worth carrying if each earns where the other cannot — and a cap is per card, which is usually the whole reason a second card pays. Best card now: at a till, a 5 % card whose monthly cap is spent is worth less than a 2 % card with room left. The stream: a recompute on any instance reaches this page over Redis pub/sub, so the number changes while you watch. Testing aid only — deleted in P19.
